# Apuntes Supremos para iPad

Este repositorio genera la app de iPad (archivo .ipa). La app abre tu versión web (https://byalvaroo.github.io/Apuntes-Supremos/), así que **se actualiza sola** cada vez que subes cambios a ese repositorio. Después de abrirla una vez con internet, funciona sin conexión.

**HECHO POR @BYALVARO__**

## Conseguir el .ipa
1. Sube estos archivos a un repositorio nuevo de GitHub, por ejemplo `Apuntes-Supremos-iPad`. Incluye la carpeta `.github`.
2. Abre la pestaña **Actions** y espera a que termine «App de iPad» (tarda unos 5–10 minutos).
3. Entra en la ejecución y descarga **ApuntesSupremos-iPad** (dentro está el `.ipa`).

## Instalarla con Sideloadly (gratis, desde Windows)
1. Instala **iTunes para Windows** (descárgalo de la web de Apple, no la versión de Microsoft Store) y **Sideloadly** (sideloadly.io).
2. Conecta el iPad por cable y pulsa «Confiar» en el iPad.
3. En Sideloadly, arrastra el `.ipa`, escribe tu Apple ID y pulsa **Start**.
4. En el iPad ve a Ajustes → General → VPN y gestión de dispositivos → tu Apple ID → **Confiar**.
5. En iPadOS 16 o posterior, activa Ajustes → Privacidad y seguridad → **Modo de desarrollador** (el iPad se reinicia).

Con un Apple ID gratuito la firma dura **7 días**. Después, vuelve a pulsar Start en Sideloadly; tus apuntes no se borran. Para que lo haga solo, activa «Automatic refresh» en Sideloadly; el PC y el iPad tienen que estar en la misma wifi.
